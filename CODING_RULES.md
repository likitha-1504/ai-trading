# Coding Rules & Engineering Standards

These standards apply to all code generated by Antigravity, Codex CLI, or human contributors.

---

## 1. General Principles
- **Clarity over cleverness**: Write explicit, well-documented, idiomatic code.
- **Fail Fast, Fail Safely**: In trading operations, errors must trigger defensive states (e.g., rejecting an order or holding off entry), never silent failures or untested fallbacks.
- **Deterministic Math**: Use `Decimal` or scaled integers for financial calculations (prices, costs, P&L, shares). Avoid raw floating-point arithmetic for monetary balances.

---

## 2. Python Backend Standards
- **Version**: Python 3.11+.
- **Typing**: Strict type hints everywhere (`mypy` / `pyright` compliant). Use Pydantic v2 for data transfer and configuration validation.
- **Async Safety**: Use `asyncio` for non-blocking I/O (FastAPI, broker websockets). Heavy computations must run in executor pools or separate processes to avoid blocking the event loop.
- **Docstrings & Comments**: Every public function and class must include docstrings explaining inputs, outputs, exceptions raised, and business rationale. Preserve existing comments.
- **No Magic Numbers**: Thresholds, timeouts, fee rates, and capital caps must reside in configuration files or typed settings classes.

---

## 3. Frontend & UI Standards
- **Framework**: React 19 with TypeScript in strict mode.
- **Styling**: Tailwind CSS with dark-mode first design tokens.
- **Component Architecture**: Modular, accessible components using `shadcn/ui` and `lucide-react`.
- **Fact vs. Opinion Segregation**:
  - Components rendering deterministic telemetry (e.g., account balance, active hard-stop, executed fills) must be visually distinct (e.g., solid badges, high-contrast borders) from components displaying AI analysis (e.g., dashed borders, "Hypothesis" watermarks, model latency tags).
- **Graceful Degradation**: Real-time feeds must display explicit disconnection, reconnection, and stale-data states.

---

## 4. Forbidden Scope & Anti-Patterns
- **No Hardcoded Secrets**: Broker API keys, tokens, and passwords must only be loaded via environment variables or encrypted configuration.
- **No Live Trading Bypasses**: Never bypass the Trade Gate or Position Watcher in production execution paths.
- **No Concurrent Multi-Writer Access**: Antigravity and Codex CLI must never write to the same files concurrently.
- **No LLM Dependency in Emergency Exits**: The Position Watcher must never await an LLM response or invoke network inference to close a position on a stop breach.
