# Implementation Task Skill

This skill defines the operational constraints for implementation workers in `ai-agent-trading`.

## Principles
1. **Bounded Scope**: Work strictly within the files and tasks assigned by Antigravity.
2. **Existing Pattern Reuse**: Reuse established architectural and coding patterns.
3. **Minimal Safe Diffs**: Avoid touching unrelated files or executing speculative refactorings.
4. **Mandatory Tests**: Every change must include or update corresponding unit/integration tests.
